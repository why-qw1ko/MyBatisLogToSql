📘 Git 常用命令速查表

Git Cheat Sheet - 日常开发必备命令

🔧 初始化与配置

命令说明
git init初始化一个新的 Git 仓库
git clone <url>克隆远程仓库到本地
git config --global user.name "name"设置全局用户名
git config --global user.email "email"设置全局邮箱
git config --list查看所有 Git 配置
git config --global core.editor "code --wait"设置默认编辑器为 VS Code

📝 基础操作

命令说明
git status查看当前状态（哪些文件被修改）
git add <file>添加指定文件到暂存区
git add .添加所有修改的文件到暂存区
git add -A添加所有文件（包括删除的文件）
git commit -m "message"提交暂存区的修改
git commit -am "message"跳过 add 直接提交（仅已跟踪文件）
git commit --amend修改最后一次提交
git restore <file>撤销工作区的修改
git restore --staged <file>从暂存区移除文件
git rm <file>删除文件并记录到暂存区
git mv <old> <new>移动/重命名文件

📜 查看历史

命令说明
git log查看提交历史
git log --oneline一行显示简洁历史
git log --graph --oneline --decorate图形化显示分支历史
git diff查看工作区与暂存区的差异
git diff --staged查看暂存区与上一次提交的差异
git show <commit>查看某次提交的详细信息
git blame <file>查看文件每行是谁修改的

🌿 分支管理

命令说明
git branch查看本地分支（当前分支带 *）
git branch -r查看远程分支
git branch -a查看所有分支（本地+远程）
git branch <name>创建新分支
git checkout <name>切换分支
git switch <name>切换分支（新命令）
git checkout -b <name>创建并切换到新分支
git switch -c <name>创建并切换到新分支（新命令）
git merge <branch>合并指定分支到当前分支
git branch -d <name>删除分支
git branch -D <name>强制删除未合并的分支
git push origin --delete <name>删除远程分支

🌍 远程仓库

命令说明
git remote -v查看远程仓库地址
git remote add origin <url>添加远程仓库
git remote set-url origin <url>修改远程仓库地址
git push origin <branch>推送分支到远程
git push -u origin <branch>推送并设置上游分支
git push --force强制推送（⚠️ 谨慎使用）
git pull拉取远程更新并合并
git fetch拉取远程更新但不合并
git clone <url>克隆远程仓库

⏪ 撤销与回退

命令说明
git reset HEAD <file>从暂存区移除文件（等同于 restore --staged）
git reset --soft HEAD~1撤销提交，保留修改
git reset --mixed HEAD~1撤销提交和暂存，保留工作区
git reset --hard HEAD~1撤销提交并删除所有修改（⚠️ 危险）
git revert <commit>生成新提交来撤销指定提交
git stash临时保存当前修改
git stash pop恢复最近的暂存并删除记录
git stash list查看所有暂存列表
git stash apply恢复暂存但保留记录
git stash drop删除暂存记录

💡 实用技巧

命令说明
git tag <name>创建标签
git push origin --tags推送标签到远程
git cherry-pick <commit>将某次提交应用到当前分支
git rebase <branch>变基操作（⚠️ 谨慎使用）
git reflog查看所有操作历史（恢复误删）
命令说明
git grep "text"在代码中搜索文本
git shortlog -sn统计每个人的提交数
git ls-files列出被追踪的文件
git archive --format=zip HEAD导出当前代码为 ZIP

❓ 常见问题

问题解决方案
fatal: not a git repository未在 Git 仓库目录中，执行 git init 或进入正确目录
failed to connect to github.com网络问题，尝试配置代理或使用 SSH 协议
Please tell me who you are未配置用户信息，执行 git config --global user.name/email
conflict (content)合并冲突，手动解决冲突后 git add 再提交
rejected (non-fast-forward)远程有更新，先 git pull 再 git push

💡 提示：使用 git help <command> 或 git <command> --help 查看详细帮助文档
